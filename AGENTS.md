This is a static GitHub Pages repository. Keep links and asset paths relative so `subsurface-model/` works under the site subpath. The scientific source files under `D:\Python_Projects\geophysical_inversion\Projects\Gasha` are read-only; regenerate derived browser data through `subsurface-model/tools/build_data.py`. Keep model arrays in `(z, y, x)` C order, northing north-to-south, depth positive downward, and plotting axes in kilometers.

The generated browser data becomes public if this repository is pushed to its public GitHub Pages source. The owner approved public access and download of these Subsurface Model display data. The Cloudflare tunnel's email allowlist does not apply to GitHub Pages. Review any newly added source data before publication.
