# Portfolio Sass source

`main.scss` assembles the theme used by the portfolio and project pages; `noscript.scss` supports the no-JavaScript variant. The source is grouped into [`base/`](base/README.md), [`components/`](components/README.md), [`layout/`](layout/README.md), and [`libs/`](libs/README.md).

The browser uses the compiled files in [`../css/`](../css/README.md), so changes here require a corresponding CSS update. This folder is part of the HTML5 UP Massively theme; preserve its attribution.
