# Portfolio media

This folder holds the portraits, project card artwork, figures, animated examples, favicon, and video used by the root HTML pages. `emad-portrait.jpg` is the current home-page portrait. `subsurface-model-preview.png` is the Subsurface Model card preview; its generation script is [`../subsurface-model/tools/build_preview.py`](../subsurface-model/tools/build_preview.py).

Images are referenced by relative path from `../index.html` and `../Project*.html`. Some card images are illustrative stock or concept imagery rather than a screenshot of the actual project. When replacing media, keep paths relative, give images meaningful `alt` text, and confirm the rights for any new public asset.
